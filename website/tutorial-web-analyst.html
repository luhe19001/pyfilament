Summarize the web with an LLM pipeline.

A follow-up to the getting-started tutorial. No web server, no extension — just a script that curls a page and asks a model for a structured brief. The same @task primitives, now wrapped around a real (flaky, pricey) LLM call.

Build it with:

What you'll build

A CLI that turns a list of URLs into structured briefs — a fetch → summarize task tree that's durable, cached, and visible in the dashboard.

What you'll learn

  • A typed PageBrief contract
  • curl inside a @task (cache + retries + limits)
  • One strict structured LLM call
  • Composing the tree and running it
  • The live dashboard

It all goes in one file; the finished scripts are examples/web_analyst_{anthropic,openai,gemini,openai_agents}.py — same pipeline, the SDK differs in one function. curl just needs to be on your PATH.

The advanced path. The OpenAI Agents SDK keeps the exact same pipeline — only step 4 changes: instead of one model call, a cheap classifier routes each page to a tuned specialist agent that can call a tool. Steps 2, 3, 5 and 6 are identical.

Point every process at one database — now. filament reads the default filament.sqlite relative to each process's working directory, and SQLite quietly creates an empty one if it's missing — that's the no such table: task_type you'll hit when the script and dashboard launch from different folders. Export an absolute path (four slashes) in your shell profile so every process shares one DB:

export FILAMENT_DB_URI="sqlite+aiosqlite:////ABS/PATH/TO/pyfilament/filament.sqlite"
2

Define the brief

One Pydantic model is the contract the model fills in — and the shape the rest of the script renders.

web_analyst_anthropicopenaigeminiopenai_agents.pycopy
from pydantic import BaseModel

class PageBrief(BaseModel):
    category: str          # news | docs | product | blog | reference | other
    title: str
    summary: str           # 2-3 sentences
    key_points: list[str]  # 3-5 bullets
    audience: str          # who the page is for

SYSTEM = ("Analyze the page's HTML and return a brief. Ignore nav and boilerplate; "
          "category is one of news|docs|product|blog|reference|other.")
3

Fetch a page with curl

Wrap the download in a @task — the base tutorial's fetch, now on the real network where the keywords earn their keep: tries rides out blips, cache skips re-downloads, rate_limit stays polite, timeout aborts a hang.

web_analyst_anthropicopenaigeminiopenai_agents.pycopy
import asyncio
from filament import task, get_logger

@task(tries=3, delay=1, timeout=30, cache=True, cache_ttl=3600, rate_limit=2)
async def fetch_page(url):
    get_logger().info(f"GET {url}")               # streams to the dashboard
    proc = await asyncio.create_subprocess_exec(
        "curl", "-sSL", "--max-time", "20", url,
        stdout=asyncio.subprocess.PIPE, stderr=asyncio.subprocess.PIPE)
    out, err = await proc.communicate()
    if proc.returncode != 0:
        raise RuntimeError(f"curl failed: {err.decode()[:200]}")
    return out.decode("utf-8", "replace")

Raw HTML is fine to send a model — no parser, just a truncate.

4

Summarize it with the LLM SDK

The model call. Structured outputs validate the reply into a PageBrief server-side — field names and types enforced — so you never get a list where you wanted a string.

web_analyst_anthropic.pycopy
from anthropic import AsyncAnthropic
client = AsyncAnthropic()                           # reads ANTHROPIC_API_KEY

async def brief(url, html):
    resp = await client.messages.parse(             # strict structured output
        model="claude-haiku-4-5",                   # fast + cheap; supports schemas
        max_tokens=4096, system=SYSTEM,
        messages=[{"role": "user", "content": f"URL: {url}\n\n{html[:8000]}"}],
        output_format=PageBrief)
    return resp.parsed_output
web_analyst_openai.pycopy
from openai import AsyncOpenAI
client = AsyncOpenAI()                              # reads OPENAI_API_KEY

async def brief(url, html):
    resp = await client.chat.completions.parse(     # strict structured output
        model="gpt-4.1",
        messages=[{"role": "system", "content": SYSTEM},
                  {"role": "user", "content": f"URL: {url}\n\n{html[:8000]}"}],
        response_format=PageBrief)
    return resp.choices[0].message.parsed
web_analyst_gemini.pycopy
import os
from google import genai
from google.genai import types
client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

async def brief(url, html):
    resp = await client.aio.models.generate_content(  # single structured call
        model="gemini-3.1-flash-lite",              # fast + cheap
        contents=f"URL: {url}\n\n{html[:8000]}",
        config=types.GenerateContentConfig(
            system_instruction=SYSTEM,
            response_mime_type="application/json",
            response_json_schema=PageBrief.model_json_schema()))
    return PageBrief.model_validate_json(resp.text)
web_analyst_openai_agents.pycopy
import re
from agents import Agent, Runner, function_tool

class PageType(BaseModel):                          # the classifier's tiny output
    category: str

@function_tool                                      # the model can call this mid-reasoning
def extract_links(html: str) -> list[str]:
    return re.findall(r'href="(https?://[^"]+)"', html)[:20]

classifier = Agent(name="Classifier", model="gpt-4.1", output_type=PageType,
    instructions="Return only the category: news|docs|product|blog|reference|other.")
news = Agent(name="News", model="gpt-4.1", output_type=PageBrief, tools=[extract_links],
    instructions="Surface a news page's high-impact stories. " + SYSTEM)
general = Agent(name="General", model="gpt-4.1", output_type=PageBrief, tools=[extract_links],
    instructions=SYSTEM)
SPECIALISTS = {"news": news}                        # category → specialist; else → general

async def brief(url, html):                         # same (url, html) → PageBrief as the others
    prompt = f"URL: {url}\n\n{html[:8000]}"
    kind = await Runner.run(classifier, prompt)     # 1) route…
    agent = SPECIALISTS.get(kind.final_output.category.lower(), general)
    out = await Runner.run(agent, prompt)           # 2) …analyze with the specialist
    return out.final_output

Same contract, any SDK. brief() returns a PageBrief whichever model ran, so everything downstream is identical — the scripts differ only here. Flip the toggle to compare; the Agents SDK swaps the single call for a classifier-plus-specialist flow.

5

Compose the tree & run it

Wrap the model call in its own @task (so it retries and caches too); analyze then chains fetch_page → summarize. Each call is a tracked child run — the same parent/child tree as the base tutorial's pipeline.

web_analyst_anthropicopenaigeminiopenai_agents.pycopy
@task(tries=3, delay=2, cache=True, cache_ttl=3600)
async def summarize(url, html):
    return await brief(url, html)                  # the SDK call from step 4

@task
async def analyze(url):
    html = await fetch_page(url)                   # child run #1
    return await summarize(url, html)              # child run #2

async def main():
    for url in ["https://www.python.org", "https://news.ycombinator.com"]:
        b = await analyze(url)
        print(f"[{b.category}] {b.title} — {b.summary}")

asyncio.run(main())

Everything from the base tutorial, now on a real model. Retries on transient 429/5xx, identical pages served from cache (run it twice — the second pass pays for no fetches and no tokens), fleet-wide rate limits, and a multi-step pipeline as one observable tree.

6

Watch it in the dashboard

Every run was recorded. Start the API and UI from the base tutorial and open localhost:3001.

terminalcopy
uvicorn filament.api.main:app --port 5006        # API
cd ui && npm install && npm run dev               # UI on http://localhost:3001

The API is a separate process — same DB rule. It reads FILAMENT_DB_URI too, so launch it with the same absolute path (step 1) or it opens its own empty filament.sqlite and every query 404s. Port :5006 taken? An old API is holding it — lsof -nP -i :5006, then kill <PID>.

Each analyze → fetch_page / summarize tree is there — states moving created → running → success, the get_logger() lines to replay, and a cache hit that turns a run green without running its body.
